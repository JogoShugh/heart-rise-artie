Link relation

allowed-now

https://jogoshugh.github.io/heart-rise-artie/rels/allowed-now

Links a resource to what may be done to it now: its state-based affordances. The target answers with JSON naming the operations allowed in the resource's current state, by their names in the API's own OpenAPI description, and a reason for each one that isn't:

{"allowed": ["pulls/update-branch"], "notAllowed": {"pulls/merge": "The branch is behind its base; update it first."}}

A client follows the link before it acts, and acts only on an operation in allowed. The link can be added by the API itself or by a layer in front of it, which can add rules of its own. It is sent as a Link header (RFC 8288), beside the API's own links.

This is the smallest form of HEART's forms relation, which links to full forms instead of operation names.

Used in

  • exhibits/allowed-now: a proxy in front of GitHub's REST API, and a client that merges only what's allowed now
