Link relation

forms

https://w3id.org/heart-rise/rels/forms

Links a resource's state (Layer 1) to its affordance set: the forms legal in its current state, shared by every resource in that state. The link carries integrity, a W3C Subresource Integrity value, and the client checks the set's bytes against it before use. Written as the CURIE hr:forms.
