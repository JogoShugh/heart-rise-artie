Link relation

in-reply-to

https://w3id.org/heart-rise/rels/in-reply-to

From an answer, and from the reply it lands on, to the request it answers: the absolute address of the watch whose 201 created it. The service sends it in each answer's _links; the reply keeps the first one and links it in every state after. An answer that names another request is refused 409 link-conflict and changes nothing. Trust rule: it must equal the Location of the 201 the caller received, and the caller checks answers' signatures with keys from that watch's hr:keys, never from a link the signer supplied. Written as the CURIE hr:in-reply-to.
