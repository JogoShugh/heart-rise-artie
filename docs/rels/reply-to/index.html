reply-to

https://w3id.org/heart-rise/rels/reply-to

In a RISE request's envelope, the caller's own reply resource: where the service answers later, by the reply's forms. Its type and profile say how to read the reply. Required with hr:keys in the envelope of a request such as a library's tell-me-when-renewable. A watch the request brings into being links it too. Written as the CURIE hr:reply-to.
