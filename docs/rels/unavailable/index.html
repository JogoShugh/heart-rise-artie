Link relation

unavailable

https://w3id.org/heart-rise/rels/unavailable

Links to a list of the acts that are not offered in this state, each with the server's reason. A client fetches it only when someone asks why an act is missing, checks it against the link's integrity, and never acts on what it lists. Written as the CURIE hr:unavailable.
