affordances

https://w3id.org/heart-rise/rels/affordances

From a service's index to its affordances: every form the service can offer, keyed by the form's integrity (hr:integrity) as the index's hr:manifest names it, each with its relation and a describedby link to the JSON Schema it uses where that schema is served apart. A client that meets an integrity it has not seen follows links from the index to the schema and never knows a schema's address in advance. Read with GET; revalidated with its ETag; open to the same callers as the index. Written as the CURIE hr:affordances.
