Link relation

keys

https://w3id.org/heart-rise/rels/keys

To the JWK Set (RFC 7517, application/jwk-set+json) of Ed25519 keys (RFC 8037) that the linking party signs with, by key id. A service that signs links it from its index and serves it open to every caller, cached a day. In a RISE request's envelope it names the keys the caller signed the request with; on a watch it names the keys the service signs its answers with, the ones the caller checks them by. A verifier takes keys only from the link of the resource it trusts, never from a link the signed message carries. Written as the CURIE hr:keys.
