progress

https://w3id.org/heart-rise/rels/progress

On a reply, while it awaits: report how far the work has got. A PATCH of the reply itself, application/merge-patch+json, with If-Match the reply's ETag, signed (RFC 9421, with Content-Digest). Minimum schema: state, the const awaiting; percent, an integer from 0 to 100; note, a string or null, where a note left out stays and null clears it; _links with hr:in-reply-to. 200 with the reply; 401 unsigned or badly signed; 409 not offered once the reply is answered, or link-conflict for another request; 412 stale; 422 invalid. Each progress is a change and is recorded in the reply's version-history. Written as the CURIE hr:progress.
