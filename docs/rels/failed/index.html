failed

https://w3id.org/heart-rise/rels/failed

On a reply, while it awaits: say the work failed. A PATCH of the reply itself whose body is an RFC 9457 problem document, application/problem+json, with If-Match, signed. Minimum schema: state, the const failed; type, a URI; title; detail, optional; _links with hr:in-reply-to. The reply is answered and keeps the problem under _embedded.problem, so its owner sees why. A body sent as merge-patch is refused 415 with Accept-Patch. Written as the CURIE hr:failed.
