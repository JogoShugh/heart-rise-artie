One Script: Real GitHub, Then Local GitLab

Claude walked a release goal once against real GitHub (JogoShugh/heart-github-test), choosing each move from what the API offered. ARTIE kept that walk as a script. The same script then released five pull requests on real GitHub and five merge requests on a GitLab running on this Mac, with no model calls, every party read at rung L2: forms and schemas each fetched by link and cached. The GitLab runs touch nothing remote: no cloud service and no enterprise system.

Both forges look the same on the wire. The script asks for typed relations, scm:pulls-get, scm:merge and scm:comment, in HAL Schema Forms. Each forge sits behind the same HEART gateway with its own connector, a few YAML files, which maps those relations and their fields to that forge's own REST API and back. Moving the script from GitHub to GitLab means changing one input: the gateway's address.
