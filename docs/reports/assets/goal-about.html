All a person writes (spec/PLAN-GOAL-MARKDOWN.md). A front matter, then the goal:

  • start: the bookmark, the one address the run begins from. Every other address comes from what the service hands over.
  • inputs: what varies per run, as a script's input() declares it. A value given on the command line wins, then the default, then the question. default: {now: PATTERN} is fresh each run.
  • limits: how many moves the run, and one step, may make.
  • The body: paragraphs, a goal in words; or paragraphs, then one list, a goal in steps. A step's sub-steps run inside what it led to. Wait: and Verify: are the two markers.
  • {name} is an input, or a resource a step named with as name; {name.member} reads its state. moves N limits one step; reasoned keeps a step an intent in the script made from the run.

Run, then generate: artie run NAME.goal.md --reasoner claude, then artie generate CAPTURE --script NAME.goal.md.
