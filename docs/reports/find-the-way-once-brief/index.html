Find the Way Once, in Brief

Why

  • The controls are in the answer. Each answer carries what is true and what can be done now, so a client finds its way from a bookmark, and a kept way runs again with no model.
  • A change is caught before a write. ARTIE holds each act to the form it was offered; a renamed field stops the step, the model repairs it once, and the repair is kept. Kept code wrote on, and was wrong.
  • The cost follows the states, not the records. One form set per state, shared by every record in it: three a run, at 6 employees or 90.
  • Data, not code. A kept script is YAML a person or a policy can read before it runs: no sandbox, no token in model-written code, and a release is a diff of a few lines.
  • Code mode and ARTIE fit together. Code mode reads the task in plain words; ARTIE does the acts. Run by a plain harness, the model is called only when ARTIE fails.
Limits said plainly
  • One service, one model, three tasks; 5 to 10 runs per row.
  • Projections are arithmetic on the measured runs, not runs.
  • A kept script does what its first run did. A goal that asked for less than the task would be kept that way: a person reviews it.
  • The example dismisses people; a gentler domain would carry the same point.
