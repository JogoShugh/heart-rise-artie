Local Models Below the Goal, in YAML

The merge watch again, with its scripts kept as data. Claude ran the goal once; artie generate wrote it as YAML; a 30B model on the laptop ran that YAML 7 times out of 7, merging every bump and telling every draft.

What changed since the first report

  • The scripts are data. In the first report (30 October) the intent and kept scripts were Kotlin, compiled on every run. Here they are YAML, run by artie run as data, with no compiler.
  • Generated, not mocked up. The October goal run kept its watch only as Kotlin, so Claude ran the goal again, and artie generate --format yaml wrote both scripts from that run: --intents for the intent form.
  • The same scene. The scratch repository, a fresh dependency bump that can be merged and a draft that can't, through the HEART gateway; the same two qwen3 30B-A3B builds through Ollama, at 1024 output tokens.

The scripts

The goal as the person wrote it, and the two forms artie generate made from Claude's run of it. Open one to read it.

The goal plain text, merge.goal.md

Claude planned it once, asking the model at 17 steps: it merged the bump, gave the draft three minutes, then labelled it and told its author why.

---
start: https://localhost:8392/
inputs:
  owner: { question: "Whose repository?" }
  repo:  { default: heart-github-test, question: "Which repository?" }
  label: { default: dependencies, question: "Which label marks a dependency bump?" }
  hold:  { default: hold, question: "Which label means a person objects?" }
  told:  { default: watch-told, question: "Which label marks a pull request the watch has told why?" }
---

Merge dependency bumps once they can be merged. Keep watching until the watch's issue is closed.

- In {owner}/{repo}
  - Open an issue titled "Merge watch", saying "Close this issue to stop the watch." `as watch`
  - Whenever a pull request labelled {label} changes `as pr`
    - If it's labelled {hold}, leave it, and say so once.
    - If it's labelled {told}, leave it.
    - Once it can be merged, merge it by squashing.
      Or give up after 3 minutes.
      Otherwise, label it {told}, then tell its author in one friendly sentence why it wasn't merged and what to do next. `reasoned`
- Until someone closes {watch}
The intent script yaml/merge.intent.heart.yaml

The goal's shape as data: the watch, the wait, the give-up. Each act is still in words, for the model to choose from what the gateway offers, on every run.

heart: 1
kind: intent
start: https://localhost:8393/

inputs:
  owner:
    question: Whose repository?
  repo:
    default: heart-github-test
    question: Which repository?
  label:
    default: dependencies
    question: Which label marks a dependency bump?
  hold:
    default: hold
    question: Which label means a person objects?
  told:
    default: watch-told
    question: Which label marks a pull request the watch has told why?

steps:
  - inferred: get repository ${owner}/${repo}
    from-intent: In ${owner}/${repo}
    then:
      - intent: Open an issue titled "Merge watch", saying "Close this issue to stop the watch."
        then:
          - keep-as: watch
  - at: https://localhost:8393/
    steps:
      - watch:
          until:
            - at: watch
              field: state
              is: closed
          steps:
            - inferred: list pull requests of ${owner}/${repo} filtered by label ${label}
              from-intent: a pull request labelled ${label} changes
              then:
                - whenever:
                    - has:
                        - field: github:labels
                          has: ${label}
                    - leave-where:
                        say: leave it, and say so once.
                        facts:
                          - field: github:labels
                            has: ${hold}
                    - leave-where:
                        say: leave it.
                        facts:
                          - field: github:labels
                            has: ${told}
                    - once:
                        offered: github:merge
                        give-up: 3m
                        steps:
                          - intent: merge it by squashing.
                            then: []
                        otherwise:
                          - intent: label it ${told}
                            reasoned: true
                          - intent: "tell its author in one friendly sentence why it wasn't merged and what to do next. The wait gave up, and the server says why: ${why}"
                            reasoned: true
The kept script yaml/merge.heart.yaml

Every act pinned to what Claude's run chose. Only the two acts after a give-up stay in words, so the model is asked only when a bump can't be merged.

heart: 1
kind: kept
start: https://localhost:8393/

inputs:
  owner:
    question: Whose repository?
  repo:
    default: heart-github-test
    question: Which repository?
  label:
    default: dependencies
    question: Which label marks a dependency bump?
  hold:
    default: hold
    question: Which label means a person objects?
  told:
    default: watch-told
    question: Which label marks a pull request the watch has told why?

steps:
  - act: github:repos-get
    fields:
      owner: ${owner}
      repo: ${repo}
    inferred: get repository ${owner}/${repo}
    from-intent: In ${owner}/${repo}
    then:
      - act: github:open-issue
        fields:
          title: Merge watch
          body: Close this issue to stop the watch.
        intent: Open an issue titled "Merge watch", saying "Close this issue to stop the watch."
        then:
          - keep-as: watch
  - at: https://localhost:8393/
    steps:
      - watch:
          until:
            - at: watch
              field: state
              is: closed
          steps:
            - act: github:pulls-list
              fields:
                owner: ${owner}
                repo: ${repo}
                labels: ${label}
              inferred: list pull requests of ${owner}/${repo} filtered by label ${label}
              from-intent: a pull request labelled ${label} changes
              then:
                - whenever:
                    - has:
                        - field: github:labels
                          has: ${label}
                    - leave-where:
                        say: leave it, and say so once.
                        facts:
                          - field: github:labels
                            has: ${hold}
                    - leave-where:
                        say: leave it.
                        facts:
                          - field: github:labels
                            has: ${told}
                    - once:
                        offered: github:merge
                        give-up: 3m
                        steps:
                          - act: github:merge
                            fields:
                              merge_method: squash
                            intent: merge it by squashing.
                            then: []
                        otherwise:
                          - intent: label it ${told}
                            reasoned: true
                          - intent: "tell its author in one friendly sentence why it wasn't merged and what to do next. The wait gave up, and the server says why: ${why}"
                            reasoned: true

Limits, and what the runs turned up

  • Three runs each. Enough to see the shape again, not to rank the builds.
  • ARTIE looks for the lock file in the wrong place. Its help says NAME.pins.yaml beside the script; it looks in the working folder. Run from exhibits/merge-watch, the YAML scripts held to the October Kotlin pins until the runs named theirs with --pins. A fix, test first, is open.
  • Not counted: a first batch lost to GitHub answering 500 to writes for a few minutes, and runs held to the wrong pins. Their outputs are kept beside these, in runs/yaml/first-batch and runs/yaml/spurious.
  • Claude's token use for the goal run wasn't recorded: the run was stopped once its watch's issue was closed, before it wrote its totals.
