Three ways through the garden

One task: build a 4 by 4 herb bed, plant basil about 2 cm deep, water it with 250 ml per cell, and check the bed. Done three ways with the same DSL and the same client, ARTIE, against the garden over CoAP on this machine, each three times, on 2026-10-17. With the garden local, the time is almost all the model's.

All 9 runs finished the task. The scripted runs took a fraction of a second, with no model. The reasoned runs took 4 to 7 seconds and reached the same end, Claude choosing the same three acts with the same fields every time. The hybrid runs took about 2 seconds, and showed the one place a model's judgement varies: the planting depth.

What it shows

  • Scripted is fast and exact. 8 to 16 times faster than the hybrid runs here, and 17 to 47 times faster than the reasoned ones, the same every time, and free. It needs someone to know the relations and fields.
  • Reasoned needs only words. “Plant basil in it, about 2 centimetres deep” became garden:sow-seed with seedType basil and depthCm 2, from the forms the garden offered, with no relation or field named in the script. It costs a model call per move, and seconds.
  • Hybrid puts judgement where it's wanted. “The herb that pesto is made from, at a sensible depth” was basil every time, at 2 cm once and 1 cm twice. Both are within the form's schema, so ARTIE accepted both; the variation is the model's, and the trace shows it.
  • Every choice is checked. The model never sees an address and never builds a request; it picks among the forms offered, and ARTIE checks the pick before anything is sent.

Not measured: model cost per run. “Model choices” counts reason steps; ARTIE asks the model once per step unless it first asks to describe a form.

The scripts

Scripted

// The garden task, scripted: every selection written down. Build a 4 by 4 herb bed, plant basil about
// 2 cm deep, water it with 250 ml per cell, and check the bed. No model.
//   artie run tests/garden-task-scripted.kts
val entry by input(default = "coap://localhost:5683/")

heart(entry) {
    act("garden:build-bed", "label" to "Herbs, scripted", "widthFt" to 4, "lengthFt" to 4) {
        act("garden:sow-seed", "seedType" to "basil", "depthCm" to 2)
        act("garden:water-cell", "milliliters" to 250)
        check(state["/cropName"] == "basil") { "the bed should hold basil" }
        check((state["/moistureLevel"] as Long) > 0) { "the bed should be watered" }
    }
}

Reasoned

// The garden task, reasoned: each move said in words; the model chooses the form and its fields from
// what the garden offers, and ARTIE checks each choice before sending it. Needs --reasoner claude.
//   artie run tests/garden-task-reasoned.kts --reasoner claude
val entry by input(default = "coap://localhost:5683/")

heart(entry) {
    reason("build a 4 by 4 foot herb bed called \"Herbs, reasoned\"") {
        reason("plant basil in it, about 2 centimetres deep")
        reason("water it with 250 millilitres per cell")
        check(state["/cropName"] == "basil") { "the bed should hold basil" }
        check((state["/moistureLevel"] as Long) > 0) { "the bed should be watered" }
    }
}

Hybrid

// The garden task, hybrid: the script builds and waters, exactly; the model makes the one choice that
// is a matter of judgement, what to plant for pesto and how deep. Needs --reasoner claude.
//   artie run tests/garden-task-hybrid.kts --reasoner claude
val entry by input(default = "coap://localhost:5683/")

heart(entry) {
    act("garden:build-bed", "label" to "Herbs, hybrid", "widthFt" to 4, "lengthFt" to 4) {
        reason("plant the herb that pesto is made from, at a sensible depth")
        act("garden:water-cell", "milliliters" to 250)
        check(state["/cropName"] == "basil") { "the bed should hold basil" }
        check((state["/moistureLevel"] as Long) > 0) { "the bed should be watered" }
    }
}
