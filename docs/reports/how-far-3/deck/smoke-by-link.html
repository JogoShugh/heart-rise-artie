The Build Links What It Made

ARTIE Follows, Then Runs

Neither address is in the script. Both came in the answer.

RISE NO-FIXED-URIS FOLLOW-NOSE

From the kept script 
- enter: ${jenkins}
  steps:
    - ask: ci:build
      fields:
        commit: ${merged.merge_commit_sha}
      reply: build
- once-answered:
    reply: build
    steps:
      - follow: hr:in-reply-to
        then:
          - run-script: ci:smoke-test
            on-link: ci:deployment
            as: smoke
