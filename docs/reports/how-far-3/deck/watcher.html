RISE · ask now, be told later

The Watcher: Tell Me When It Offers Merge

Ask Once

watcher:watch: this resource, the relation scm:merge, and a reply form to answer on.

It Looks, as HEART

Every 3 seconds: does the pull request’s answer offer scm:merge now?

Be Told Later

completed, signed, when it does. failed, not offered in time, when it never does.

It doesn’t know what a pull request is. It knows what an offer is.

RISE HYPERTEXT

From the kept script 
- enter: ${watcher}
  steps:
    - ask: watcher:watch
      fields:
        resource: ${pr.@self}
        offers: scm:merge
      reply: watch
- once-answered:
    reply: watch
    steps:
      - enter: ${pr.@self}
        steps:
          - act: scm:merge
            fields:
              method: squash
