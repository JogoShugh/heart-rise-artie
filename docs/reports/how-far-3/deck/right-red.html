Every Run Through the Runner

A raw test command is blocked; it would leave nothing in the log. Each run leaves one line: pass or fail, total, failures. No results at all is logged as a failure, with the reason.

RIGHT-BEHAVIOR

Raw test commands are blocked (core/gate-bash.sh)
#!/usr/bin/env bash
# PreToolUse (Bash). For wrapper-logged stacks: blocks running the raw test
# command, because a raw run leaves no BDD_RUN fact and the pre-commit check
# then cannot see the red/green sequence. No-op unless bddRawCommandRegex is set.
set -o pipefail
. "$(dirname "$0")/lib.sh"

bdd_has_config || exit 0
regex=$(bdd_value bddRawCommandRegex)
[ -n "$regex" ] || exit 0

command=$(jq -r '.tool_input.command // empty')
[ -n "$command" ] || exit 0
case "$command" in *bdd-gates/bdd-run.sh*) exit 0 ;; esac

if printf '%s\n' "$command" | grep -Eq -- "$regex"; then
  echo "Blocked: run tests through .claude/bdd-gates/bdd-run.sh [extra args] so the BDD_RUN result is logged." >&2
  exit 2
fi
exit 0
Every run leaves one line, even a failed compile (stacks/gradle-kotlin/templates/bdd-run-logging.gradle.kts)
// bdd-gates: records "BDD_RUN PASS|FAIL" after every test run, including failed ones.
// Needs: import java.time.Instant and java.time.temporal.ChronoUnit at the top of the build script.

val logBddRun by tasks.registering {
    group = "verification"
    description = "Appends a BDD_RUN fact to .claude/tdd-events.log for the pre-commit TDD-ordering check."
    doLast {
        // RESULT_XML: the JUnit XML written for the Cucumber suite runner class.
        val resultFile = file("build/test-results/test/TEST-<your.package>.RunCucumberTest.xml")
        val logFile = file(".claude/tdd-events.log")
        val timestamp = Instant.now().truncatedTo(ChronoUnit.SECONDS)
        logFile.parentFile.mkdirs()
        if (!resultFile.exists()) {
            // No result file means compilation or discovery failed: still red.
            logFile.appendText("$timestamp BDD_RUN FAIL reason=no-results\n")
            return@doLast
        }
        val xml = resultFile.readText()
        fun attr(name: String) = Regex("""$name="(\d+)"""").find(xml)?.groupValues?.get(1) ?: "0"
        val status = if (attr("failures") == "0" && attr("errors") == "0") "PASS" else "FAIL"
        logFile.appendText(
            "$timestamp BDD_RUN $status total=${attr("tests")} failures=${attr("failures")} errors=${attr("errors")}\n",
        )
    }
}

tasks.test {
    finalizedBy(logBddRun)
}
