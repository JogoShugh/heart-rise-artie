The kept script (release.heart.yaml)
steps:
  - act: scm:pulls-get
    fields:
      owner: ${owner}
      repo: ${repo}
      pull_number: ${pull}
    intent: Open pull request ${pull} of ${owner}/${repo}
    then:
      - keep-as: pr
  - enter: ${watcher}
    steps:
      - ask: watcher:watch
        fields:
          resource: ${pr.@self}
          offers: scm:merge
        reply: watch
  - once-answered:
      reply: watch
      steps:
        - enter: ${pr.@self}
          steps:
            - act: scm:merge
              fields:
                method: squash
              intent: merge it by squashing
              then:
                - check:
                    - field: state
                      is: closed
                    - field: merged
                      is: true
                    - field: mergeable_state
                      is: unknown
                - keep-as: merged
  - enter: ${jenkins}
    steps:
      - ask: ci:build
        fields:
          commit: ${merged.merge_commit_sha}
        reply: build
  - once-answered:
      reply: build
      steps:
        - follow: hr:in-reply-to
          intent: follow its in-reply-to link to the build
          then:
            - run-script: ci:smoke-test
              on-link: ci:deployment
              inputs:
                book: ${book}
                author: ${author}
                renewable: ${renewable}
                problem: ${problem}
                comment: ${comment}
              as: smoke
  - given:
      - at: smoke
        field: passed
        is: true
    then:
      - enter: ${dev}
        steps:
          - act: env:get-environment
            fields:
              id: ${environment}
            inferred: get environment ${environment}
            from-intent: open environment ${environment} and promote commit {merged.merge_commit_sha}, citing {smoke.passing} of {smoke.of} scenarios passed
            then:
              - act: env:promote
                fields:
                  commit: ${merged.merge_commit_sha}
                  smoke: # review: the reasoner chose it, asked "promote commit 30a0fa96e3eed2ae20b2b5fa7613a115d56312a3, citing 5 of 5 scenarios passed"
                    passed: ${smoke.passing}
                    of: ${smoke.of}
                intent: open environment ${environment} and promote commit {merged.merge_commit_sha}, citing {smoke.passing} of {smoke.of} scenarios passed
                then:
                  - check:
                      - field: commit
                        is: ${merged.merge_commit_sha}
    otherwise:
      - at: ${pr.@self}
        steps:
          - act: scm:comment
            fields:
              body: "Not promoted to Dev: smoke scenarios ${smoke.failed} failed."

Kept YAML (ARTIE)

  • Data. No loops, imports or eval to review.
  • Every act names a relation the server must still offer.
  • Pinned by hash: a changed form stops the replay.
  • Runs with no model, in any HEART client.

Code Mode

  • The model writes TypeScript or Python against tool APIs.
  • What you keep is a program: code review, sandbox, dependencies.
  • It can call anything its bindings expose, in any order.
  • A real step up from tool lists in context.
