UpdateClientCertificate

Changes information about an ClientCertificate resource.

Request Syntax
PATCH /clientcertificates/clientcertificate_id HTTP/1.1
Content-type: application/json
{
   "patchOperations": [ {
      "from": "string",
      "op": "string",
      "path": "string",
      "value": "string"
   } ]
}

clientcertificate_id The identifier of the ClientCertificate resource to be updated. Required: Yes

PatchOperation · op Valid Values: add | remove | replace | move | copy | test

DeleteClientCertificate

Deletes the ClientCertificate resource.

Request Syntax
