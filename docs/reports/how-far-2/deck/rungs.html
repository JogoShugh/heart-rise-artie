L0, L1, L2: one page, three ways to deliver it

Like a page with its CSS and JavaScript inlined, or linked and cached.

L0

State, forms and schemas in one answer

Simple and correct: like a page with everything inlined.

L1

Prefer: forms=link

The form set is its own content-addressed link, cached.

L2

Prefer: forms=link, schema=link

Schemas linked too: immutable, shared across forms, states and resources.

“L0 buys correctness, L2 buys economy.” HTTP caching does the scaling, as it always has on the Web.
