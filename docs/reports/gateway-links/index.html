URL members are string members of the state whose value is an address. The pull request grew from 19.2 KB to 27.5 KB: every link now carries its media type, and each embedded user and repository carries its own links (about forty on a repository). Nothing was dropped.

What the gateway does

  • Only the members the connector names are read: *_url and url, and a pull request's own _links. No other data is scanned for addresses.
  • A link to a GitHub API resource the connector serves (a GET in its include list) is rewritten to the gateway's address, under that operation's relation: comments_url becomes github:issues-list-comments.
  • Any other API link keeps GitHub's address, typed application/vnd.github+json. Web pages, images, .diff and .patch stay GitHub's, typed by host and suffix.
  • A URI template is a templated link, and is never taken for a path the gateway serves.
  • Users and repositories with their own address are embedded, each with its own self and links; their data stays.
