How it was compared

  • Side by side. SpringCloneTrace (in heart-sims/src/test) sends each request to the clone, then the same request to the example. It stops the run at the first difference in status, Content-Type, Location, ETag or body. Both write every link absolute, against the address they were asked at, so the example's origin is written as the clone's before the bytes are compared. Nothing else is changed. The tab Side by side shows each exchange, with the example's own answer as its comparison.
  • ARTIE. wild/fresh-run/explore.kts, the script first run against the example on 2026-11-02, run again on each, with only its entry changed for the clone. The two tabs ARTIE on show each run line by line.
  • Both started fresh before each run: the example's container restarted, the clone reset.

Not covered

  • A method sent in lower case, as the templates write it: Tomcat refuses post with 405 (2026-11-02 log). The clients here send methods upper case, so neither run sends one.
  • The example's other modules, and errors it has no code for, such as a body that isn't JSON.
