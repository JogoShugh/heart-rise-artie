  1. scm:pulls-get
    Read merge request 504, kept as pr.
  2. state, merged
    GitLab’s merged becomes state: closed, merged: true.
  3. head.sha
    GitLab’s sha: it merges only if the source head is still there.
  4. scm:merge {method: squash}
    “Changes merged into main with 8ef9444b (commits were squashed).”
  5. scm:comment {body}
    The same comment, as a GitLab note.
