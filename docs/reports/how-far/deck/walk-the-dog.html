How this was built

Walk the dog, ship the feature

When there’s no time left to type code: family, a new dog, a phone in one hand and a leash in the other.

  • Claude Code Remote Control on the phone, a personal Max account at home.
  • Test first, every change: Gherkin, a red run, the code, a green run, a gated commit.
  • Evidence, not trust: the gates log every step, so what passed is on record when I get home.
  • The result: repeatable, reliable RISE behaviour, built a few sentences at a time.

The hooks that gate every change (core/hooks.json)
