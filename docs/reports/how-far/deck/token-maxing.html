Why this talk

From token maxing to tokenomics

“You are all having way too much fun burning way too many tokens”

Kelsey Hightower, opening ZTA: Zero Token Architecture, WeAreDevelopers World Congress North America, 26 Sep 2026

Agents that run inference on every call burn tokens and work against zero trust. Infer once, then run the result as reliable, deterministic code.

The talk

Token maxing

Companies ranked engineers by tokens burned. Meta’s internal leaderboard covered 85,000+ employees.

The bill

Per-token prices for GPT-4-class models fell about 98% since late 2022. Enterprise AI bills rose anyway: volume.

The turn

The FinOps Foundation’s J.R. Storment: from tokenmaxxing and “go fast” to guardrails and control. Ashish Bhatia: enablement first, governance next.

Token maxing re-learns the API on every call. Tokenomics learns it once and keeps something that stays true. What keeps it true?
