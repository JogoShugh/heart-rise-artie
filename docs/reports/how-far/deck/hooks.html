How it was built · Determinism through hooks

Instructions are advisory. Hooks are not.

GateWhereWhat it holds
Gherkin firstPreToolUseNo production code until a scenario says what it must do
Red, loggedPostToolUseA failing test run is recorded before the first src/main write
Green to stopStopThe session can’t end with the suite red
Ordering at commitgit pre-commitThe log must show feature, red, code, green, in that order
Gate protectionPreToolUseThe gates and their log can’t be edited by the model

Claude Code hooks guard the edits; git hooks guard the history.
