The deck's relations

deck:ref

A reference note the slide shows as a pill: a source's own words, quoted whole, with where they come from (describedby). Each note is one resource, under refs/, embedded whole in every slide that names it, so a client shows it with no further request.

deck:fragment

A fragment of source code the slide shows on demand, read from its file when the deck was built. via links the file and lines on GitHub.
