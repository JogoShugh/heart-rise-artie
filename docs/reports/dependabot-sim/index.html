The goal file, run by ARTIE itself

Then ARTIE learned the words: artie run dependabot-sim.goal.md --reasoner claude runs the goal file below as written. Claude decides each part once, the first time the run needs it, on a real pull request; every later pull request and every later look replays the decision, with no model.

dependabot-sim.goal.md
---
start: https://localhost:8392/
inputs:
  owner: { question: "Whose repository?" }
  repo:  { default: heart-github-test, question: "Which repository?" }
  label: { default: dependabot, question: "Which label marks a pull request to merge?" }
  hold:  { default: hold, question: "Which label means a person objects?" }
manners: alongside-others
---

Merge the pull requests labelled {label} once they can be merged, unless a person labels them {hold}. Keep
watching until the watch's own issue is closed.

## Working alongside others

Other people work in this repository while you do. What they decide stands.

- Don't undo or write over anything someone else changed since you looked. Look again, and work from what's there now.
- When a step no longer makes sense because of what someone did, leave it, and say why.
- Nothing you write may claim something that isn't so: "merged" only once it is.
- Don't say again what has already been said.

## The work

- In {owner}/{repo}
  - Open an issue titled "Auto-merge watch", saying "Close this issue to stop the watch." `as watch`
  - Whenever a pull request labelled {label} changes `as pr`
    - If it's labelled {hold}, leave it, and say so once.
    - Once it can be merged, merge it by squashing.
      Or give up after 10 minutes.
      Otherwise, say on {pr} why it wasn't merged.
- Until someone closes {watch}

## Done when

- Every pull request labelled {label} during the watch is merged, or says why not
- Nothing anyone else decided was undone: no pull request labelled {hold} was merged

Two Whenevers at once: Dependabot, and a security scan

The same watch, with a second Whenever beside it: each issue a security scan opens, labelled scan, is answered once. Whenevers side by side are one watch, each a listener on a thread of its own, with a client of its own, so a slow read under one holds up only that one. Each one's first look is made in turn, as the goal lists them, so Claude decides in the goal's order; after that, every look replays.

dependabot-scan.goal.md
---
start: https://localhost:8392/
inputs:
  owner: { question: "Whose repository?" }
  repo:  { default: heart-github-test, question: "Which repository?" }
  label: { default: dependabot, question: "Which label marks a pull request to merge?" }
  hold:  { default: hold, question: "Which label means a person objects?" }
  scan:  { default: scan, question: "Which label marks a failed security scan?" }
manners: alongside-others
---

Merge the pull requests labelled {label} once they can be merged, unless a person labels them {hold}. At the same
time, answer each issue a security scan opens, labelled {scan}. Keep watching until the watch's own issue is closed.

## Working alongside others

Other people work in this repository while you do. What they decide stands.

- Don't undo or write over anything someone else changed since you looked. Look again, and work from what's there now.
- When a step no longer makes sense because of what someone did, leave it, and say why.
- Nothing you write may claim something that isn't so: "merged" only once it is.
- Don't say again what has already been said.

## The work

- In {owner}/{repo}
  - Open an issue titled "Auto-merge and scan watch", saying "Close this issue to stop the watch." `as watch`
  - Whenever an issue labelled {scan} changes `as finding`
    - Say on {finding} "Seen by the watch: a person will look at this scan.", unless it's said already.
  - Whenever a pull request labelled {label} changes `as pr`
    - If it's labelled {hold}, leave it, and say so once.
    - Once it can be merged, merge it by squashing.
      Or give up after 10 minutes.
      Otherwise, say on {pr} why it wasn't merged.
- Until someone closes {watch}

## Done when

- Every pull request labelled {label} during the watch is merged, or says why not
- Nothing anyone else decided was undone: no pull request labelled {hold} was merged

Seven live runs, to every give-up saying why in the gateway's own words

  1. g12 stopped
    Stopped before its first look. The planner reached each list from the start, and Whenevers side by side were refused that.
    Fixed: Each listener looks from where its own list is reached, the start or where the watch stands.
  2. g13 stopped
    Commented on scan issue #718 at every look: its own comment changed the issue, and the next look took that as a change. Stopped by hand after two.
    Fixed: Once a Whenever's steps are done at a member, the member is read again and remembered as it is; only someone else's change is answered.
  3. g14 did the work, then failed a check
    Merged #723, answered each scan issue once, left the held pull requests alone; stopped at the first give-up: a pull request offered no comment through the gateway.
    Fixed: A pull request offers github:comment, open or closed, posted on the issue it also is: issues/create-comment with the pull request's number.
  4. g15 stopped
    The If "labelled hold" was decided as a check that held on every pull request, so it left them all; the capture didn't say which check it was.
    Fixed: Each check a watch decides is kept in the capture, with where it was decided; the planner is told an If's check holds exactly when its condition is true.
  5. g16 did the work, then failed a check
    The If was right, and #726 was merged. The Otherwise found no comment: the restarted gateway couldn't bind its port, and the old one kept answering.
    Fixed: The gateway restarted for real (an operations slip, not a code change).
  6. g17 stopped
    Each of eight stuck pull requests got one comment, and no more after; but the reason was made up from mergeable_state, and each said it would be merged once it could be.
    Fixed: An Otherwise is told its wait gave up, and the server's own reason, to say that reason in the server's words and promise nothing the watch won't do.
  7. g18 finished
    Nine pull requests each got one comment, in the gateway's own words: a draft (#728, #715, #695, #682), conflicts (#685, #683), or branch protection (#716, #697, #688). Decided once, at the first; replayed for the rest with no model.

The goal words, as the code they came down to

Before ARTIE read the words, watch.kts wrote each by hand in heart-script, through the HEART gateway; heart-script's watch, whenever and once now keep them, and a goal run decides them.

  1. Wheneveract("github:pulls-list", … "sort" to "updated", "direction" to "desc"), read down to the first one older than the last look
  2. Onceoffers("github:merge"), then act("github:merge", "merge_method" to "squash")
  3. Give upthe time since it was taken up, against giveUp minutes; never on a reason that says to read again
  4. Otherwiseact("github:comment") with why("github:merge"), the gateway's hr:unavailable reason, unless a watch already said it
  5. Untilthe watch opens its own issue, and reads it at the end of every look; closed, it stops
  6. Mannershold in the labels it holds now leaves the pull request alone; a refused act is read again next look, never sent again blind

Found and fixed on the way

    Each look catches a failure, says so, and the next look tries again.
    runs/watch-1023-watch1.out
  2. Restarted, the watch commented on #682, #683 and #685 a second time.
    Before it comments, it reads the pull request's comments and says nothing a watch already said. A fourth watch said nothing new.
    runs/watch-1023-watch4.out
  3. It once gave up on "GitHub is still checking… read it again shortly", telling #683 something untrue.
    It doesn't give up on a reason that says to read again; it waits one more look.
    runs/watch-1023-watch3.out

Still missing

  • gateway No checks resource. A failed check and a pending one give the same reason, "a required check or review is missing".
  • HEART hr:unavailable has no mark for a reason that passes by itself; the watch reads the words "read it again".
  • gateway No reviews resource, so a person objects with a label rather than "changes requested".
  • gateway List pages carry no ETag, so each look reads the list in full from the gateway (GitHub answers it 304).
  • heart-script The trace keeps every representation in full; a long watch's journal should keep only what changed. --remember keeps what a watch did, not the whole journal.
  • ARTIE Done when over many resources ("every pull request was merged, or says why") is noted, not checked: the run would have to answer from its own record.
  • ARTIE artie generate doesn't yet write a decided watch run as a script with no model in it (spec/PLAN-WATCH-GOALS.md, slice 4c).
  • ARTIE "Say it, unless it's said already" is decided as a chain; the planner put the comment before the check in g13 and g14, and after it in g15. A watch doesn't answer its own comment, but someone else's comment replays the chain.
  • ARTIE --remember isn't kept per listener, so a watch with listeners run again does what it did again.
  • ARTIE An Otherwise's step, in the trace and the output, carries the whole of what its reasoner was told, not only the planner's words.

// The Dependabot goal (exhibits/goal-syntax/goals/dependabot.goal.md), written by hand in heart-script before the
// goal words Whenever, Until, Once, Otherwise and Give up exist (spec/ideas/goals-that-work-alongside-others.md,
// "Review, 2026-10-23"). Each word is the loop or the branch it will come down to:
//   Until    the watch opens its own issue and stops when someone closes it (or after hours, a safety stop).
//   Whenever the open pull requests, most recently updated first, are read down to the last one seen unchanged;
//            each labelled label is taken up. Events are hints: this is the polling kind, and the gateway asks
//            GitHub with its copy's ETag, so a look at an unchanged pull request costs nothing against the limit.
//   Once     a pull request taken up is merged by squashing as soon as it offers github:merge.
//   Manners  one labelled hold is left alone, and the watch says so once; a refused merge is read again and
//            decided again next time round, never sent again blind.
//   Give up  after giveUp minutes without the merge offered;
//   Otherwise the pull request is told why, in the gateway's own words (hr:unavailable).
//   artie run watch.kts owner=JogoShugh gateway=https://localhost:8392/
val owner by input(question = "Whose repository?")
val repo by input(default = "heart-github-test", question = "Which repository?")
val label by input(default = "dependabot", question = "Which label marks a pull request to merge?")
val hold by input(default = "hold", question = "Which label means a person objects?")
val every by input(default = "15", question = "How many seconds between looks?")
val giveUp by input(default = "10", question = "Give up on a pull request after how many minutes?")
val hours by input(default = "2", question = "Stop the watch after how many hours at most?")
val stamp by input(
    default = java.time.LocalDateTime.now().format(java.time.format.DateTimeFormatter.ofPattern("MMdd-HHmmss")),
)
val gateway by input(default = "http://localhost:8392/", question = "Where is the gateway?")

val repository = arrayOf("owner" to owner, "repo" to repo)
val deadline = java.time.Instant.now().plusSeconds(hours.toLong() * 3600)

/** A remark, kept in the run's record and shown as the run goes (a note alone is not shown). */
fun Here.tell(text: String) {
    note(text)
    println("  note: $text")
}

/** How each comment the watch leaves begins, so a later watch knows what was said. */
val WATCH = "Not merged by the auto-merge watch"

/** Whether the server's reason for not offering an act says it will pass by itself. */
fun passing(why: String?): Boolean = why.orEmpty().contains("read it again")

/** What the watch says, once, of a pull request a person objected to. */
fun leftAlone(number: Long) = "#$number is labelled $hold: left alone until the label goes."

/** The names of the labels the held pull request carries, read from the labels it embeds. */
fun Here.labelled(): Set<String> = embedded("github:labels").mapNotNull { it.read["name"] as? String }.toSet()

heart(gateway) {
    var watch = 0L
    act("github:repos-get", *repository, intent = "get the repository $owner/$repo") {
        act("github:open-issue", intent = "open the issue that keeps the watch going", fields = {
            "title" to "Auto-merge watch ($stamp)"
            "body" to "Pull requests labelled `$label` are merged once they can be; `$hold` keeps one back. " +
                "Close this issue to stop the watch."
        }) {
            watch = state.long("number")
        }
    }

    val waiting = mutableMapOf<Long, java.time.Instant>() // taken up, not yet merged: since when
    val heldBack = mutableSetOf<Long>() // left alone for the hold label, said once
    val finished = mutableSetOf<Long>() // merged, or given up on
    var seen: String? = null // the newest updated_at read so far
    var open = true

    while (open && java.time.Instant.now() < deadline) {
        // A look that fails (GitHub answered 5xx, the network dropped) is noted; the next one tries again.
        try {
            // Whenever: what changed since the last look, newest first, down to the first one older than that.
            act("github:pulls-list", *repository, "state" to "open", "sort" to "updated", "direction" to "desc") {
                var newest = seen
                for (title in links("item").filterNotNull()) {
                    var older = false
                    follow("item", title) {
                        val updated = state.text("updated_at")
                        val number = state.long("number")
                        older = seen != null && updated < seen!!
                        if (!older) {
                            if (newest == null || updated > newest!!) newest = updated
                            val labels = labelled()
                            when {
                                number in finished || label !in labels -> Unit
                                hold in labels -> {
                                    waiting.remove(number)
                                    if (heldBack.add(number)) tell(leftAlone(number))
                                }
                                else -> {
                                    heldBack.remove(number)
                                    waiting.putIfAbsent(number, java.time.Instant.now())
                                }
                            }
                        }
                    }
                    if (older) break
                }
                seen = newest
            }

            // Once each one waiting can be merged, merge it; or give up after giveUp minutes.
            for ((number, since) in waiting.toMap()) {
                try {
                    act("github:pulls-get", *repository, "pull_number" to number) {
                        val waited = java.time.Duration.between(since, java.time.Instant.now())
                        when {
                            state["state"] != "open" -> {
                                tell("#$number was closed or merged by someone else: left as it is.")
                                finished += number
                            }
                            hold in labelled() -> {
                                if (heldBack.add(number)) tell(leftAlone(number))
                                waiting.remove(number)
                            }
                            offers("github:merge") -> {
                                act("github:merge", intent = "merge #$number by squashing", fields = {
                                    "merge_method" to "squash"
                                    "commit_title" to "${state.text("title")} (#$number)"
                                }) {}
                                finished += number
                            }
                            // A reason that says to read again is a passing one (GitHub working mergeability out):
                            // giving up on it would tell the pull request something untrue, so wait one more look.
                            // The words stand in for a mark hr:unavailable doesn't have yet: temporary or not.
                            waited.toMinutes() >= giveUp.toLong() && !passing(why("github:merge")) -> {
                                // Otherwise: say why it wasn't merged, in the gateway's words.
                                val why = why("github:merge") ?: "the merge was never offered"
                                follow("github:issues-get") {
                                    // Said already, by this watch or an earlier one: not said again.
                                    var said = false
                                    follow("github:issues-list-comments") {
                                        said = links("item").filterNotNull()
                                            .any { it.startsWith(WATCH) && it.endsWith(": $why") }
                                    }
                                    if (said) tell("#$number: already told why, by an earlier watch.")
                                    else act("github:comment", intent = "say why #$number wasn't merged", fields = {
                                        "body" to "$WATCH (#$watch) after $giveUp minutes: $why"
                                    }) {}
                                }
                                finished += number
                            }
                        }
                    }
                } catch (stopped: ScriptStopped) {
                    // Refused (someone moved it since it was read): read again and decide again next time round.
                    tell("#$number: ${stopped.reason}; looked at again next time.")
                }
                if (number in finished) waiting.remove(number)
            }

            // Until someone closes the watch's issue.
            act("github:issues-get", *repository, "issue_number" to watch) {
                open = state["state"] == "open"
            }
        } catch (failed: Exception) {
            tell("A look failed: ${failed.message}; looking again next time.")
        }
        if (open) Thread.sleep(every.toLong() * 1000)
    }
}

fun Any?.map(): Map<String, Any?> = (this as? Map<*, *>).orEmpty().entries.associate { it.key.toString() to it.value }
fun Any?.list(): List<Map<String, Any?>> = (this as? List<*>).orEmpty().map { it.map() }
fun Map<String, Any?>.text(key: String) = this[key]?.toString().orEmpty()
fun esc(s: String) = s.replace("&", "&amp;").replace("<", "&lt;").replace(">", "&gt;").replace("\"", "&quot;")

val yaml = Yaml().load<Any?>(File(data).readText()).map()
val rounds = yaml["rounds"].list()
val pulls = rounds.flatMap { it["pulls"].list() }

fun pr(number: Any?) = """<a class="mono" href="$repo/pull/$number" rel="noopener" target="_blank">#$number</a>"""
fun tag(tone: String, words: String) = """<span class="tag $tone">${esc(words)}</span>"""
val outcomeWords = mapOf("good" to "right", "safe" to "stopped, said why", "bad" to "harm", "quiet" to "nothing")
val runWords = mapOf("good" to "finished", "safe" to "did the work, then failed a check", "bad" to "stopped")

fun count(by: String, tone: String) = pulls.count { it.text("by") == by && it.text("tone") == tone }
val tiles = listOf(
    Triple("good", count("watch", "good"), "the watch did the right thing: merged, or left a held one alone"),
    Triple("safe", count("watch", "safe"), "the watch gave up and said why, in the gateway's words"),
    Triple("bad", count("watch", "bad"), "the watch did harm"),
    Triple("bad", count("rival", "bad"), "GitHub's auto-merge merged over a person's hold"),
).joinToString("") { (tone, n, says) ->
    """<div class="tile $tone"><b>$n</b><span class="sub">${esc(says)}</span></div>"""
}

val timelines = yaml["timelines"].list().joinToString("\n") { t ->
    val events = t["events"].list().joinToString("") { e ->
        val tone = e.text("tone").ifEmpty { "quiet" }
        """<li class="$tone"><span class="at">${esc(e.text("at"))}</span><span>${esc(e.text("what"))}</span></li>"""
    }
    """<div class="timeline"><h3>${pr(t["number"])} with ${esc(t.text("by"))}</h3><ol>$events</ol></div>"""
}

val roundSections = rounds.joinToString("\n") { r ->
    val rows = r["pulls"].list().joinToString("\n") { p ->
        val tone = p.text("tone")
        val who = if (p.text("by") == "rival") "GitHub's auto-merge" else "the watch"
        """<li class="pull $tone"><div class="head">${pr(p["number"])} ${tag(tone, outcomeWords[tone] ?: tone)}""" +
            """<span class="sub">${esc(who)}</span></div><div>${esc(p.text("what"))}</div>""" +
            """<div class="outcome">${esc(p.text("outcome"))}</div></li>"""
    }
    """<section><h2>${esc(r.text("name"))}</h2><p class="sub">${esc(r.text("setting"))} """ +
        """Output: <span class="mono">${esc(r.text("out"))}</span>.</p><ol class="pulls">$rows</ol></section>"""
}

val words = yaml["words"].list().joinToString("\n") { w ->
    """<li><b>${esc(w.text("word"))}</b><code>${esc(w.text("code"))}</code></li>"""
}
val fixed = yaml["fixed"].list().joinToString("\n") { f ->
    """<li><div>${esc(f.text("what"))}</div><div class="outcome">${esc(f.text("fix"))}</div>""" +

}
/** Each live run of a goal file, as a row: what it found, and what was fixed. */
fun runs(key: String) = yaml[key].list().joinToString("\n") { r ->
    val tone = r.text("tone")
    val fixed = r.text("fixed").takeIf { it != "-" }?.let { """<div class="sub">Fixed: ${esc(it)}</div>""" }.orEmpty()
    """<li class="pull $tone"><div class="head"><b class="mono">${esc(r.text("run"))}</b> ${tag(tone, runWords[tone] ?: tone)}</div>""" +
        """<div>${esc(r.text("found"))}</div>$fixed</li>"""
}

}
