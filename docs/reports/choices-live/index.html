What it shows

  • Asked in words for someone who can't be chosen now, Claude refused each time and named who can. It was shown only the values the server will take, so it had nothing else to pick.
  • By script, ARTIE refused the same values before anything was sent. Sent past ARTIE, the server refused it with 422 at /playerNumber.
  • The tickets choices follow state in another resource. Once the ticket went urgent, Marco and Tom dropped out and Priya was the only agent left.
  • "Someone who can take it now" with two agents to choose from is ambiguous. ARTIE's reasoner asks rather than guess, as it is told to. Saying "now" in the choices' description did not change that, and was not kept.
  • HAL-FORMS can say these choices only as values for one game. It cannot make them depend on the team field, so it offers both teams' players. HAL Schema Forms keeps the form the same for every game and leaves the values in state.
