The goal: github-task.goal.yaml

All a person writes: where to start, the inputs, and the goal in words.

All a person writes. Three keys, nothing else:

  • start: the bookmark, the one address the run begins from. Every other address comes from what the server hands over.
  • inputs: what varies per run, declared as a script's input() would. A value given on the command line (owner=JogoShugh) wins, then the default, then the question. With none of these, and no one to answer, the run stops before its first request. Four forms: name: value (a default), name: (must be given), name: {default, question}, and default: {now: PATTERN}, a fresh value each run, as a java.time pattern.
  • goal: the task in words, one paragraph or one step per line. $name reads an input.

Run, then generate:

artie run github-task.goal.yaml owner=JogoShugh \
  --reasoner claude --rung L2 --trace github-task.trace.yaml
artie generate github-task.trace.yaml \
  --out github-task-from-goal.kts --script github-task.goal.yaml

inputs:
  owner:
    question: Whose repository?
  repo:
    default: heart-github-test
    question: Which repository?
  stamp:
    default: { now: MMdd-HHmmss }
goal: |
  In $owner/$repo, open an issue titled "Crash when a bed has no name (reasoned)", saying it was opened by a
  HEART script.
  From the main branch, start a new branch named fix-blank-names-reasoned-$stamp, commit a file named
  fix-reasoned-$stamp.md to it saying "Bed names may not be blank." with the message "Refuse a bed with no name",
  and open a pull request into main titled "Refuse a bed with no name (reasoned)", saying it relates to the issue.
  Wait until the pull request can be merged, merge it by squashing its commits, and make sure it merged.
  Then go back to the issue, comment "Fixed in 1.2 by #<the pull request's number>.", and close it as completed.
  Make sure it is closed as completed.
