Three Ways Through GitHub

One GitHub task from the bookmark, through the HEART gateway, into the scratch repository: open an issue, branch from main, commit the fix, open a pull request that relates to the issue, wait until GitHub can merge it and merge it, then comment on the issue and close it. Done three ways, three live runs each, on 2026-10-18: every selection scripted; every move said in words for Claude to choose; and scripted but for one judgement call.

What the live runs caught

These nine runs are the third round. The first two found five things, each fixed test-first before the next round; their traces are kept beside the runs', outside the repository.

  • A reasoned run chose GitHub's own github:branches, the template …/branches{/branch}, over the gateway's github:repos-list-branches, and ARTIE refused it: “no binding for the scheme null: https://api.github.com/repos/JogoShugh/heart-github-test/branches{/branch} was refused, and nothing was sent”. ARTIE and heart-mcp now offer a model only links they can follow: no templates, nothing outside HEART (a156baf).
  • Claude then named the gateway's untitled link with the title "", which ARTIE matched against none. A blank title is now no title (f494ff4).
  • Every reasoned run's committed file held base64, not the text: the form passed on GitHub's words for content, “using Base64 encoding”, so Claude encoded it, and the gateway encoded it again. The runs' checks never read the file, so they passed. A field the gateway encodes is now described as plain text (e171027), and every file is read back from GitHub after the runs.
  • After twenty-odd runs, main was on the second page of the repository's branches. A reasoned run, not finding it on the first, asked rather than guessed; the scripted way would have failed. The task now names the branch, through the bookmark's branch lookup, as a person would.
  • The live smoke test, before any run, caught two places the fake GitHub had GitHub wrong: branches are listed without their own address, and a branch writes its links as plain strings (b588100, 47b1a9f).
  • Left open in the scratch repository by stopped attempts: issues #22, #32 and #48.

The scripts

Scripted

// The GitHub task, scripted: every selection written down, no model. From the bookmark: open an issue, branch
// from main, commit the fix, open a pull request that relates to the issue, wait until GitHub can merge it and
// merge it, then comment on the issue that it is fixed in 1.2 and close it. Real writes, to the repository given.
//   artie run tests/github-task-scripted.kts owner=JogoShugh repo=heart-github-test
val owner by input()
val repo by input()
val stamp by input(default = java.time.LocalDateTime.now().format(java.time.format.DateTimeFormatter.ofPattern("MMdd-HHmmss")))

heart("http://localhost:8392/") {
    var issue = 0L
    var pull = 0L
    act("github:repos-get", "owner" to owner, "repo" to repo) {
        act("github:open-issue", "title" to "Crash when a bed has no name (scripted)", "body" to "Opened by a HEART script.") {
            issue = state["/number"] as Long
        }
    }
    // The branch is named, as a person would: a list of branches is paged, and main may not be on its first page.
    act("github:repos-get-branch", "owner" to owner, "repo" to repo, "branch" to "main") {
        act("github:branch-from-here", "name" to "fix-blank-names-scripted-$stamp") {
            act(
                "github:commit-file",
                "path" to "fix-scripted-$stamp.md",
                "message" to "Refuse a bed with no name",
                "content" to "Bed names may not be blank.\n",
            )
            act(
                "github:open-pull-request",
                "title" to "Refuse a bed with no name (scripted)",
                "base" to "main",
                "body" to "Relates to #$issue.",
            ) {
                pull = state["/number"] as Long
                // GitHub works out whether it can merge a new pull request a moment after it opens.
                until(tries = 20) { offers("github:merge") }
                act("github:merge", "merge_method" to "squash")
                check(state["/merged"] == true) { "the pull request should be merged" }
            }
        }
    }
    act("github:issues-get", "owner" to owner, "repo" to repo, "issue_number" to issue) {
        // The comment is a new resource: visit it, then come back to the issue to close it.
        act("github:comment", "body" to "Fixed in 1.2 by #$pull.") {
            check(state["/body"] == "Fixed in 1.2 by #$pull.") { "the comment should say what fixed it" }
        }
        act("github:close")
        check(state["/state"] == "closed") { "the issue should be closed" }
        check(state["/state_reason"] == "completed") { "the issue should be closed as completed" }
    }
}

Reasoned

// The GitHub task, reasoned: each move said in words; the model chooses the form or link and its fields from what
// the gateway offers, and ARTIE checks each choice before sending it. The same task as github-task-scripted.kts.
// Needs --reasoner claude. Real writes, to the repository given.
//   artie run tests/github-task-reasoned.kts owner=JogoShugh repo=heart-github-test --reasoner claude
val owner by input()
val repo by input()
val stamp by input(default = java.time.LocalDateTime.now().format(java.time.format.DateTimeFormatter.ofPattern("MMdd-HHmmss")))

heart("http://localhost:8392/") {
    var issue = 0L
    var pull = 0L
    reason("open the repository $owner/$repo") {
        reason("open an issue titled \"Crash when a bed has no name (reasoned)\", saying it was opened by a HEART script") {
            issue = state["/number"] as Long
        }
    }
    reason("open the branch main of $owner/$repo") {
        reason("start a new branch from here, named fix-blank-names-reasoned-$stamp") {
            reason("commit a file named fix-reasoned-$stamp.md, saying \"Bed names may not be blank.\", with the message \"Refuse a bed with no name\"")
            reason("open a pull request into main titled \"Refuse a bed with no name (reasoned)\", saying it relates to #$issue") {
                pull = state["/number"] as Long
                // GitHub works out whether it can merge a new pull request a moment after it opens.
                until(tries = 20) { offers("github:merge") }
                reason("merge it, squashing its commits")
                check(state["/merged"] == true) { "the pull request should be merged" }
            }
        }
    }
    reason("open issue $issue in $owner/$repo") {
        // The comment is a new resource: visit it, then come back to the issue to close it.
        reason("comment on it: Fixed in 1.2 by #$pull.") {
            check(state["/body"] == "Fixed in 1.2 by #$pull.") { "the comment should say what fixed it" }
        }
        reason("close it, since the fix is done")
        check(state["/state"] == "closed") { "the issue should be closed" }
        check(state["/state_reason"] == "completed") { "the issue should be closed as completed" }
    }
}
