Scene six · a month laterFiction

A company of fifteen

A month later. The library has added company groups, and Harbor Point Logistics has signed up all fifteen of its staff.

Priya

Can the assistant renew for the whole company?

Sam

Once the model finds the way. It searched the members by company, five to a page, and went through all three pages: every member, every book.

Priya

And the script it kept?

Sam

Names no one. A loop over every member the search lists, page after page, and inside it, a loop over each member's books. If Harbor Point has twenty staff next month, it goes through four pages.

Priya

And Ana's script, from before the company groups?

Sam

Still runs. Its forms didn't change.

79model calls, once, to find the way
0model calls each run after
14books renewed, each once, across 15 members
inputs:
  company:

steps:
  - act: library:search-members
    fields:
      company: ${company}
    then:
      - whenever:              # every member, page after page
          - whenever:          # every book each one has out
              - when-offered:
                  - act: library:renew
The run, and the library's release
  • The first run: Claude Sonnet 5.5, ARTIE at L2, for Harbor Point; 79 calls; 369,436 input tokens (228,342 sent, 141,094 read from cache); 13,641 output; 111 steps.
  • Kept by artie generate, which writes a list as one loop when the run opened every member of every page, following each page's next link; a member's own list is a loop inside it. The same in Kotlin: whenever { whenever { whenOffered … } }.
  • Run with no model on a fresh library: 110 steps, the same fourteen books renewed, each once; the nine with a hold waiting or at the limit left.
  • The release: search-members finds the members of a company group, five to a page, each page linking the next. The accounts search is as it was, so member.heart.yaml, pinned before the release, ran after it unchanged.
