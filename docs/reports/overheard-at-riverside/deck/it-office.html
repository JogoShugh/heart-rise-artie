Scene three · todayFiction

The IT office

Today, the library's IT office. Priya builds the library's API; Sam builds the assistant that renews books for members.

Priya

The loans API is done. JSON over HTTP, with a full OpenAPI description: every operation, every field, every status code.

Sam

My agent read all of it, found Ana's loans, and sent a renew for The Hobbit. 409. Hold waiting.

Priya

Well, that's correct.

Sam

Correct, and the first the agent heard of the hold. Renew is listed for every loan.

Priya

It has to be. The description is the same for every loan in every state. The rule's in the text.

Sam

So the agent reads English, guesses the rule, and finds out by trying. A document beside the data, every address, the same for every state, filled in by hand. That's forms.yaml. We gave people better than that in 1997. The real 1997, I mean: pages had forms.

Priya

Ana's page gets a grey button with the reason. My API gets a 409.

Sam

Same server, same rules. Different manners.

The two documents, side by side
1997: the Perl site's forms.yaml 
/loans/{loanId}/renew:
  post:
    summary: Renew a loan
    description: Only while it is renewed
      fewer than three times and no one's
      hold is waiting.
    responses:
      '200': renewed
      '409': it cannot be renewed
Today: heart-core's OpenAPI twin 
/loans/{id}/actions/renew:
  post:
    description: Offered while the book is out,
      renewed fewer than three times, and
      no one's hold is waiting.
    requestBody: { $ref: Renew }
    responses:
      '200': The loan after the act
      '409': NotOffered

Both list renew for every loan, always. forms.yaml is the OpenAPI of the web that wasn't, and forms.html its Swagger UI. Whether this loan can be renewed now, each says only after the call.
