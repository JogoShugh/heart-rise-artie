The idea, in three steps

A goal file says, in plain words, what a watch over a greenhouse bench should do. Claude decides how to do each part once, the first time it comes up. Those decisions are written down as a script. From then on the script does the work by itself, with no model, and costs no tokens.

What the goal says

Alerts from the bench sensors are answered once and handed to the grower on duty. Sowing plans are merged when they fit the bench, and told why when they don't. Trays are closed once transplanted. Anything a person labels hold is left alone.

seed-bench.goal.md
---
start: https://localhost:8392/
inputs:
  owner:  { question: "Whose repository?" }
  repo:   { default: heart-github-test, question: "Which repository?" }
  week:   { default: "43", question: "Which sowing week?" }
  grower: { question: "Who is on duty at the bench?" }
  hold:   { default: hold, question: "Which label means a person objects?" }
manners: alongside-others
---

Keep the seed bench moving for week {week}: sow each plan once it passes the bench check, answer
every alert once and hand it to the grower on duty, and close each tray once it is transplanted.
Keep watching until the bench watch's own issue is closed.

## Working alongside others

Growers move trays, relabel them and write on them by hand. What they decide stands.

- Don't undo or write over anything someone else changed since you looked.
- Leave anything labelled {hold} alone, and say so once.
- Nothing you write may claim something that isn't so: "sown" only once the plan is merged.
- Don't say again what has already been said.

## The work

- In {owner}/{repo}
  - Open an issue titled "Bench watch, week {week}", saying "Close this issue to stop the watch." `as watch`
  - Whenever an issue labelled alert changes `as alert`
    - If it's labelled {hold}, leave it, and say so once.
    - Say on {alert} "Seen by the bench watch; {grower} will check the tray today.", unless it's said already.
    - Assign it to {grower}.
  - Whenever a pull request labelled sowing changes `as plan`
    - If it's labelled {hold}, leave it, and say so once.
    - Once it can be merged, merge it by squashing.
      Or give up after 5 minutes.
      Otherwise, say on {plan} why it wasn't merged, unless it's said already.
  - Whenever an issue labelled tray changes `as tray`
    - If it's labelled transplanted, close it.
- Until someone closes {watch}

## Done when

- Every alert during the watch says it was seen, once, and is assigned to {grower}
- Every sowing plan is merged, or says why not
- Nothing labelled {hold} was changed

The script made from the run

What artie generate wrote from run b20. It reads values again where they came from: the grower and the hold label are inputs, and the reason a merge gave up is the server's, read at the time.

generated/seed-bench.kts
// Generated by artie generate from runs/bench-1024-b20.yaml, the run of ../goal-syntax/goals/seed-bench.goal.md.
// Every selection as that run made it, nested as it nested, with no model.
// What it was offered is pinned in generated/seed-bench.pins.yaml, held to before every act.
//   artie run generated/seed-bench.kts owner=JogoShugh grower=JogoShugh
import kotlin.time.Duration.Companion.minutes
val owner by input(question = "Whose repository?")
val repo by input(default = "heart-github-test", question = "Which repository?")
val week by input(default = "43", question = "Which sowing week?")
val grower by input(question = "Who is on duty at the bench?")
val hold by input(default = "hold", question = "Which label means a person objects?")

heart("https://localhost:8392/") {
    var watchAt = ""

    act("github:repos-get", "owner" to owner, "repo" to repo, intent = "get repository $owner/$repo") {
        act("github:open-issue", intent = """Open an issue titled "Bench watch, week $week" with the body "Close this issue to stop the watch."""", fields = {
            "title" to "Bench watch, week $week"
            "body" to "Close this issue to stop the watch."
        }) {
            watchAt = held.address
        }
    }
    listeners(until = { var over = false; at(watchAt) { over = holds(mapOf("state" to "closed")) }; over }) {
        listen("an issue labelled alert changes", from = "https://localhost:8392/") {
            act("github:issues-list-for-repo", "owner" to owner, "repo" to repo, "labels" to "alert") {
                whenever {
                    if (holds(mapOf("github:labels" to listOf("alert")))) {
                        if (holds(mapOf("github:labels" to listOf(hold)))) note("Left ${held.address}: leave it, and say so once.") else {
                            var undone1 = false
                            follow("github:issues-list-comments") { undone1 = holds(mapOf("item" to listOf("Seen by the bench watch; ${grower} will check the tray today."))) }
                            if (!undone1) act("github:comment", "body" to "Seen by the bench watch; ${grower} will check the tray today.") {}
                            act("github:assign", "assignees" to listOf(grower)) {}
                        }
                    }
                }
            }
        }
        listen("a pull request labelled sowing changes", from = "https://localhost:8392/") {
            act("github:pulls-list", "owner" to owner, "repo" to repo, "labels" to "sowing") {
                whenever {
                    if (holds(mapOf("github:labels" to listOf("sowing")))) {
                        if (holds(mapOf("github:labels" to listOf(hold)))) note("Left ${held.address}: leave it, and say so once.") else {
                            once("github:merge", giveUp = 5.minutes, otherwise = { why ->
                                var undone2 = false
                                follow("github:issues-list-comments") { undone2 = holds(mapOf("item" to listOf("Not merged: Branch protection blocks the merge: a required check or review is missing."))) }
                                if (!undone2) act("github:comment", "body" to "Not merged: ${why}") {}
                            }) {
                                act("github:merge", "merge_method" to "squash") {}
                            }
                        }
                    }
                }
            }
        }
        listen("an issue labelled tray changes", from = "https://localhost:8392/") {
            act("github:issues-list-for-repo", "owner" to owner, "repo" to repo, "labels" to "tray") {
                whenever {
                    if (holds(mapOf("github:labels" to listOf("tray")))) {
                        if (holds(mapOf("github:labels" to listOf("transplanted")))) {
                            act("github:close") {}
                        }
                    }
                }
            }
        }
    }
}

// The seed bench as a page: a goal file run by ARTIE with Claude, the script made from that run, and the script run
// with no model. The facts live in results.yaml; this script only lays them out. The look comes from the reports'
// shared assets (report-shell.html, report-base.css, theme-switch.js), inlined.
//   artie run report.kts out=../../docs/reports/seed-bench/index.html artifact=/tmp/seed-bench.html
// out gets a whole document for GitHub Pages; artifact, when given, the same page without the document skeleton.
import java.io.File
import org.yaml.snakeyaml.Yaml

val data by input(default = "results.yaml", question = "Where are the results?")
val out by input(question = "Where to write the page?")
val artifact by input(default = "", question = "Where to write the artifact copy, if anywhere?")
val source by input(default = "report.kts", question = "Where is this script, to show it on the page?")
val assets by input(default = "../../docs/reports/assets", question = "Where are the reports' shared assets?")

fun Any?.map(): Map<String, Any?> = (this as? Map<*, *>).orEmpty().entries.associate { it.key.toString() to it.value }
fun Any?.list(): List<Map<String, Any?>> = (this as? List<*>).orEmpty().map { it.map() }
fun Map<String, Any?>.text(key: String) = this[key]?.toString().orEmpty()
fun esc(s: String) = s.replace("&", "&amp;").replace("<", "&lt;").replace(">", "&gt;").replace("\"", "&quot;")

val yaml = Yaml().load<Any?>(File(data).readText()).map()
val runs = yaml["runs"].list()
val toneWords = mapOf("good" to "did it right", "safe" to "stopped, nothing harmed", "bad" to "told someone twice")

fun tag(tone: String) = """<span class="tag $tone">${esc(toneWords[tone] ?: tone)}</span>"""
val claudeRuns = runs.count { it.text("run").startsWith("b") }
val scriptRuns = runs.count { it.text("run").startsWith("g") }
val fixes = runs.count { it.text("fixed") != "-" }
val tiles = listOf(
    Triple("quiet", claudeRuns, "live runs with Claude deciding"),
    Triple("good", scriptRuns, "live runs of the script alone, no model"),
    Triple("safe", fixes, "things found and fixed, each with a test first"),
    Triple("good", 0, "model calls in the runs of the script"),
).joinToString("") { (tone, n, says) -> """<div class="tile $tone"><b>$n</b><span class="sub">${esc(says)}</span></div>""" }

val proof = yaml["proof"].list().mapIndexed { i, p ->
    val arrow = if (i > 0) """<div class="arrow" aria-hidden="true">↓</div>""" else ""
    """$arrow<div class="node"><b>${esc(p.text("step"))}</b><div>${esc(p.text("what"))}</div>""" +
        """<div class="outcome">${esc(p.text("showed"))}</div></div>"""
}.joinToString("")

val runRows = runs.joinToString("\n") { r ->
    val tone = r.text("tone")
    val fixed = r.text("fixed").takeIf { it != "-" }?.let { """<div class="sub">Fixed: ${esc(it)}</div>""" }.orEmpty()
    """<li class="pull $tone"><div class="head"><b class="mono">${esc(r.text("run"))}</b> ${tag(tone)}</div>""" +
        """<div>${esc(r.text("found"))}</div>$fixed</li>"""
}
val gaps = yaml["gaps"].list().joinToString("\n") { g ->
    """<li><span class="tag quiet">${esc(g.text("where"))}</span> ${esc(g.text("what"))}</li>"""
}
