The body is not of a type the act takes

https://w3id.org/heart-rise/problems/unsupported-media-type

415: the act's body is of another type than the act takes, such as a failure sent as merge-patch rather than as a problem document. accepted lists the types the resource takes, as does Accept-Patch (RFC 5789) for a PATCH, or Accept-Post for a POST.
