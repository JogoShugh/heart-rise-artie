https://w3id.org/heart-rise/problems/signature-required

401: the act carries no signature where the resource takes only signed acts (RFC 9421 over Content-Digest, RFC 9530). The answer says how to sign: WWW-Authenticate names the Signature scheme, declared by the HAL Schema Forms profile, and Accept-Signature names the components, @method, @target-uri, content-digest and if-match, and the key id to sign with.
