Finds an employee by exact full name via search (must match exactly one), reads with getEmployee (fresh etag), and updates the role by appending a suffix (default ", retired") using If-Match. Note: update body field is "position" while the response shows "role". On 412 re-reads and retries (up to 3). Skips if role already ends with suffix. Args: name (default "Frodo Baggins"), suffix (default ", retired"). Raises on unexpected status.
